# Google sign-in icon

`google_g.png` is Google's unmodified multicolour G, downloaded on 20 October
2026 from the image linked in the official
[Sign in with Google branding guidance](https://developers.google.com/identity/branding-guidelines):
[source PNG](https://developers.google.com/static/identity/images/g-logo.png).

SHA-256: `d1ce9c2af0b10a7333abc99bc706f9a6a199e5b65bf3e3009624f076b8638e6a`.

Use it only with the labelled Google authentication action. Preserve its colours
and proportions. The app renders it without a colour filter on a white button;
the icon is decorative for accessibility because the button already has a label.
