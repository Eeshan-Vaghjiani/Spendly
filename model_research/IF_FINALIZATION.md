## Running the notebook

`Spending_Isolation_Forest_Finalization.ipynb` is standalone and output-free. Its
embedded modules are generated by `build_if_final_notebook.py` from reviewed
Python source; tests check rebuild identity. It uses no network downloads.

1. Use an isolated CPU environment with `if_final_requirements.txt`.
2. Attach original R3 `manifest.json`, `train.zip`, `calibration.zip`,
   `validation.zip`. ZIPs may be at root or under `development/`.
3. Set INPUT_ROOT, choose a new OUTPUT_ROOT and set RUN_DEVELOPMENT=True.
4. Run and download the entire run folder/ZIP before leaving temporary compute.

The completed verification environment was Python3.10.6, numpy1.26.4,
pandas2.3.3, scikit-learn1.7.2, joblib1.6.0. Versions are recorded per run, not
silently upgraded. Use the saved version exactly for trusted-local reload.

Output directories refuse overwrites. Failed attempts remain identifiable and
require a fresh output directory. There is no claim of resumable partial fits.
Only reload self-produced trusted joblib: hashes detect accidental corruption,
not malicious authorship. Keep model binaries and row-level evidence local.
